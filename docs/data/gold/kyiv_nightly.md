# kyiv_nightly

## Що це

Один рядок це одна ніч D для рішення о 22:00 за Києвом: спати в коридорі чи в кімнаті ([ADR-0010](../../adr/0010-night-question.md)). Файл `data/gold/kyiv_nightly.parquet`: 159 ночей з 2026-05-04 по 2026-10-09, 63 колонки, ракетних ночей 30. Код `src/airalerts/gold/kyiv_nightly.py`, тест `tests/test_nights.py`.

## Звідки

Лише з gold `kyiv_hourly` ([опис](kyiv_hourly.md)), який сам пройшов тест на витік:

| колонки | означення |
|---|---|
| `t_utc` | година рішення: 22:00 D за Києвом, в UTC |
| ознаки рядка 22:00 | усі ознаки `kyiv_hourly` рядка t_utc, крім `hour_kyiv` (завжди 22) і `y_strike_3h` |
| `s1_takeoff_48h`, `s1_takeoff_72h` | сума `s1_takeoff_24h` рядків t, t - 24 год (і t - 48 год) |
| `s4_drone_waves_24h` | сума `s4_drone_waves_6h` рядків t, t - 6, t - 12, t - 18 год |
| `threat_hours_48h`, `ballistic_hours_48h`, `alert_minutes_48h` | сума відповідної 24-годинної ознаки рядків t і t - 24 год |
| `attack_last_night` | ціль ночі D - 1 (відома о 08:00 D) |
| `attack_nights_7`, `attack_nights_14`, `attack_nights_28` | ракетних ночей серед 7, 14 і 28 ночей перед D (ночі до 2026-05-04 рахуються як тихі: ударів до 2026-05-14 у даних немає) |
| `nights_since_attack` | ночей від останньої ракетної ночі, 30 якщо такої немає за 30 ночей |
| `night_date` | дата D (за Києвом) |
| `y_night` | ціль: ракетний удар по Києву з 22:00 D до 08:00 D+1 |

`y_night` дорівнює OR `y_strike_3h` рядків 22:00, 01:00, 04:00 і 05:00: їхні вікна [t, t + 3 год) разом точно покривають ніч. Ніч починається з 2026-05-04, бо сумам потрібні 72 год погодинних рядків від T0.

## Перевірка

`tests/test_nights.py`:
- файл дорівнює свіжій збірці;
- кожну ніч перебудовано з погодинних рядків до 22:00 D, у яких стерто мітки, невідомі о 22:00 (t + 3 год > 22:00 D): кожна ознака та сама;
- ціль дорівнює годинам удару з silver від 22:00 до 08:00;
- жодна ознака не дорівнює цілі.

Підкладений витік (`attack_last_night` з цілі самої ночі D) тест ловить.

## Як перебудувати

.venv/bin/python -I -m airalerts.gold.kyiv_hourly    # спершу погодинний gold
.venv/bin/python -I -m airalerts.gold.kyiv_nightly
